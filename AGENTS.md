# Eclipse DnD Forge — Codex context

Этот файл — короткий маршрутизатор проекта. Общие правила Codex, Git, UX и security находятся в глобальном `AGENTS.md` и `E:/projects/AGENTS.md`; не дублировать их здесь.

## Перед работой

1. Подтвердить точный Git root, текущую ветку и dirty state.
2. Прочитать `E:/projects/AGENTS.md`, этот файл и `docs/PROJECT-CONTEXT.md`.
3. Найти существующий статус или handoff именно текущей задачи; не считать старые roadmap доказательством готовности.
4. Читать только файлы, необходимые для запроса.

## Цель продукта

Forge должен поддерживать три одинаково важные игровые модели: общий стол с живым Game Master и игроками; AI Game Master с группой игроков; одиночную игру с AI Game Master.

## Критерий готовности

Режим считается рабочим после реального сценария: создать или подключить сессию, выбрать персонажа, начать игру, выполнить действие, изменить состояние мира, сохранить, переподключиться и безопасно завершить сессию. UI и HTTP 200 сами по себе не являются доказательством.

## Проверка изменений

Для realtime, AI, сохранения и UI проверять пользовательский путь и ошибки восстановления. Не ослаблять разрешения, секреты или проверки ради прохождения теста. После работы указать точные команды и что осталось непроверенным.
